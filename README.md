# How to Configure Text Replacement Shortcuts on iOS

## Overview
This guide instructs end-users on how to configure the native Text Replacement feature on iOS. This utility allows users to map short text triggers (e.g., "myaddress") to automatically expand into longer, complex text strings (e.g., a full mailing address), reducing manual data entry friction and input errors.

## Prerequisites
* An Apple iPhone running iOS 15 or later.
* Access to the native device Settings application.

## Step-by-Step Instructions

### 1. Navigate to Keyboard Settings
1. Open the **Settings** application on the iOS home screen.
2. Scroll down and tap **General**.
3. Tap **Keyboard** to open text input configurations.

### 2. Add a New Text Shortcut
1. Tap **Text Replacement** near the top of the interface.
2. Tap the **Plus sign (+)** icon located in the upper-right corner of the screen.

### 3. Configure the Expansion String and Shortcut Trigger
1. Tap the **Phrase** input field.
2. Type or paste the full text string you want to display when expanded (Example: `john.doe@email.com`).
3. Tap the **Shortcut** input field.
4. Type the specific, low-friction text trigger you wish to use (Example: `@@`).
   * *Note: Ensure the trigger is a unique combination of characters to prevent unintentional expansions during standard typing.*

### 4. Verify and Save Configuration
1. Tap **Save** in the top-right corner.
2. Open any app that allows text input (such as Messages or Notes).
3. Type your custom shortcut trigger (`@@`) and press the **Spacebar**.
4. Confirm that the shortcut automatically expands into your full configured phrase.
